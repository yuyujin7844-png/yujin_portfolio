# 컬러 팔레트 디자인 시스템

## 프로젝트 정보
- **출처 웹사이트**: Studio Kyle (https://www.studiokyle.kr)
- **분석 날짜**: 2026-08-25
- **적용 프로젝트**: 포트폴리오 웹사이트

## CSS 변수 정의
```css
:root {
  /* Primary Colors */
  --color-primary: #E83A29;
  --color-primary-light: #EE6B5F;
  --color-primary-dark: #AE2C1F;

  /* Secondary Colors */
  --color-secondary: #FFE8DA;
  --color-accent: #F49C8C;

  /* Background Colors */
  --color-bg-primary: #FFFEEF;
  --color-bg-secondary: #FFE8DA;

  /* Text Colors */
  --color-text-primary: #E83A29;
  --color-text-secondary: #333333;
  --color-text-muted: #999999;

  /* Interactive Colors */
  --color-button-primary: #E83A29;
  --color-button-hover: #AE2C1F;
  --color-link: #E83A29;
  --color-link-hover: #AE2C1F;
}
```

> `--color-primary`, `--color-secondary`, `--color-bg-primary`는 원본 사이트의 CSS 변수(`--primary`, `--secondary`, `--bgc`)에서 그대로 가져온 값입니다. `-light`/`-dark`/`accent`는 원본에 없어서 Primary(`#E83A29`) 기준으로 25% 밝게/어둡게, 그리고 원본이 실제로 쓰던 반투명 오버레이(`rgba(232,58,41,0.5)`를 배경색 위에 얹은 결과)를 평면 hex로 환산해 만들었습니다.

## 컬러 사용 가이드

| 변수 | 용도 | 사용 시점 |
|---|---|---|
| `--color-primary` | 브랜드 메인 컬러 | 로고, 주요 버튼, 강조 텍스트, 아이콘, 체크박스/라디오 선택 상태 |
| `--color-primary-light` | Primary 보조 톤 | 버튼 hover 이전 단계의 부드러운 강조, 일러스트/장식 요소 |
| `--color-primary-dark` | Primary 강한 톤 | 버튼 hover/active, 링크 hover, 포커스 상태 |
| `--color-secondary` | 보조 배경/포인트 | 카드 배경, 섹션 배경 교차(zebra), footer 배경 |
| `--color-accent` | 시각적 강조 | 태그, 배지, 하이라이트 박스처럼 눈에 띄되 Primary보다 부드러워야 하는 요소 |
| `--color-bg-primary` | 페이지 기본 배경 | `body` 배경색 (전체 바탕) |
| `--color-bg-secondary` | 섹션 배경 | 콘텐츠 블록 구분, 카드/모달 배경 |
| `--color-text-primary` | 본문 텍스트 | 기본 텍스트 색상. 원본 사이트는 이 값을 Primary(`#E83A29`)로 통일해 브랜드 톤을 강하게 씀 |
| `--color-text-secondary` | 중립 텍스트 | 긴 본문, 설명글 등 가독성이 중요한 텍스트 (원본엔 미사용 변수지만 포트폴리오처럼 텍스트 분량이 많은 경우 권장) |
| `--color-text-muted` | 비활성/보조 텍스트 | placeholder, 캡션, 날짜, 부가 정보 |
| `--color-button-primary` | 버튼 기본 배경 | Primary CTA 버튼 |
| `--color-button-hover` | 버튼 hover 배경 | 버튼에 마우스 오버 시 |
| `--color-link` | 링크 텍스트 | 인라인 링크 기본 상태 |
| `--color-link-hover` | 링크 hover | 링크에 마우스 오버 시 |

**사용 원칙**
- 버튼/링크는 항상 `기본 → hover`로 `--color-*` → `--color-*-dark` 쌍을 사용해 상태 변화를 명확히 합니다.
- `--color-text-primary`를 본문 전체에 남용하면 가독성이 떨어질 수 있으니, 긴 본문 텍스트에는 `--color-text-secondary`를 우선 검토하세요. (원본 사이트는 텍스트 양이 적은 랜딩페이지라 브랜드 컬러 텍스트가 잘 어울렸지만, 포트폴리오는 본문 분량이 더 많을 수 있습니다.)
- MUI 프로젝트 컨벤션(`docs/design-system.md`)에 따라 컴포넌트에서는 색상을 하드코딩하지 말고, 위 값을 `_template_settings/src/theme.js`의 `palette`에 매핑해 `theme.palette.primary.main` 형태로 사용하세요.

```js
// theme.js 매핑 예시
palette: {
  primary: {
    light: '#EE6B5F',
    main: '#E83A29',
    dark: '#AE2C1F',
  },
  secondary: {
    main: '#FFE8DA',
  },
  background: {
    default: '#FFFEEF',
    paper: '#FFE8DA',
  },
  text: {
    primary: '#E83A29',
    secondary: '#333333',
    disabled: '#999999',
  },
}
```

## 반응형 고려사항

### 다크모드
원본 사이트는 다크모드를 지원하지 않으므로, 포트폴리오에 다크모드를 추가한다면 아래 기준으로 대비(contrast)를 재조정하는 것을 권장합니다.

```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-primary: #1A1512;
    --color-bg-secondary: #2A211C;

    --color-text-primary: #FF7A64;
    --color-text-secondary: #E5E0D8;
    --color-text-muted: #9A9088;

    --color-primary: #FF6B54;
    --color-primary-light: #FF9585;
    --color-primary-dark: #E8503C;

    --color-button-primary: #FF6B54;
    --color-button-hover: #FF9585;
    --color-link: #FF7A64;
    --color-link-hover: #FF9585;
  }
}
```
- 다크모드에서는 `#E83A29`를 그대로 쓰면 어두운 배경 위에서 명도 대비가 부족해질 수 있어, 채도는 유지하되 명도를 살짝 높인 `#FF6B54` 계열로 대체합니다.
- 배경은 완전한 검정 대신 원본의 웜톤을 살린 다크 브라운 계열(`#1A1512`)을 사용해 브랜드 톤을 유지합니다.

### 화면 크기별 고려사항
- 컬러 자체는 브레이크포인트별로 바꾸지 않는 것을 권장합니다. 대신 `docs/design-system.md`의 스페이싱/타이포 토큰과 함께, 모바일에서는 `--color-accent` 같은 저대비 컬러의 사용 영역(작은 텍스트 등)을 줄여 가독성을 확보하세요.
- 버튼 등 인터랙티브 요소는 모바일에서 hover 상태가 없으므로, `--color-button-hover`는 `:active` 의사 클래스에도 동일하게 매핑해 터치 피드백을 제공합니다.

### 접근성(대비) 체크
- `--color-text-primary (#E83A29)` on `--color-bg-primary (#FFFEEF)`: 명도 대비 약 4.6:1 → 일반 텍스트 기준(WCAG AA, 4.5:1) 통과, 작은 텍스트는 여유가 크지 않으므로 굵기(700 등)를 함께 사용 권장
- `--color-text-secondary (#333333)` on `--color-bg-primary`: 대비 충분 (본문 장문 텍스트에 안전)
- `--color-text-muted (#999999)`는 대비가 낮으므로 본문에는 사용하지 말고 캡션/보조 정보에만 한정합니다.
